# AI-Based Placement Readiness Analytics
Streamlit app (Python, Pandas, NumPy, scikit-learn, Matplotlib).

## Run
    pip install -r requirements.txt
    python generate_data.py      # creates placement_data.csv (100,000 students)
    streamlit run app.py

## Pages
Home, Student Assessment, Placement Prediction, Readiness Score,
Skill Gap & Recommendations, Model Performance, Analytics Dashboard.
